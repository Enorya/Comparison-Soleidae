# Comparison of Soleidae

This repository contains the scripts and result files of the structural variants (SVs) calling and synteny analysis from the paper (in revision): Geslain et al., Comparison of Soleidae flatfishes reveals synteny, structural variation, a candidate sex-determining gene and recent speciation

The scripts are sorted by analysis type.
- The ones for the SV calling can be regrouped by steps:

    1. [Minimap2](Scripts/Structural_variants/minimap2.sh) contains the commands used to map the long Pacbio HiFi reads to the genome of *Solea senegalensis*
    2. [Dygsu](Scripts/Structural_variants/dygsu.sh), [NGSEP](Scripts/Structural_variants/NGSEP.sh) and [Sniffles2](Scripts/Structural_variants/sniffles2.sh) contains the commands used to call the SVs
    3. [SV_filtering](Scripts/Structural_variants/SV_filtering.sh) contains the commands used to filter and merge the detected SVs
    4. [Orthogonal_validation](Scripts/Structural_variants/orthogonal_validation.sh) contains the commands used to validate by mapping the genome of *S. senegalensis* to the reference genome of *S. solea* and calling SVs between them
    5. [Validated_SV_retrieval](Scripts/Structural_variants/validated_SV_gathering.sh) contains the commands used to retrieve only the validated SVs via assembly-to-assembly validation

- The ones for the synteny analysis are divided like this:

    1. [NtSynt](Scripts/Synteny_analysis/ntSynt.sh) contains the commands to run the synteny analysis
    2. [Plotting_all_chromosomes](Scripts/Synteny_analysis/Synteny_figure_plotting_with_all_chromosomes.Rmd) and [Plotting_per_chromosome](Scripts/Synteny_analysis/Synteny_figure_plotting_k_per_k.Rmd) contains the R code to generate the ribbon plots

The folder `Structural_variant_files` contains the result files of the SV calling. It's divided into 3 sub-folders:
- `SV_callings` which contains the basic SV calling files for the following 3 calling tools.
- `SV_filtering` contains the filtered SV vcf files for the 3 datasets.
- `SV_validated` contains the final VCF file with the validated set of SV in it.

The folder `Synteny_files` contains the files generated by the ntSynt script and necessary for the making of the ribbon plots.
